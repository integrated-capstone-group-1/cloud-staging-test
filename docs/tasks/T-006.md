# Task T-006: Customer Onboarding, Identity & JWT Session Service

**Goal:** Implement customer registration with auto-provisioned primary PHP account, login with BCrypt verification, 15-minute access JWT issuance, and Redis token blacklisting.

**Requirement IDs:** BR-07, BR-16, BR-20, TR-S01, TR-S02, TR-S09

## 2. In-Scope Contract Slice
* `POST /api/auth/register`:
  1. Inserts into `customer_master` (name, email, contact).
  2. Inserts into `app_user_master` with BCrypt-hashed password.
  3. Calls `accounts-service` to auto-provision one primary `PHP` pocket in `account_master` (`is_primary = 'Y'`).
* `POST /api/auth/login`:
  * Validates credentials against `app_user_master`.
  * Generates short-lived access JWT (15-min expiry) with claims: `sub=customerId`, `role=CUSTOMER`.
  * Generates rotating refresh token.
* `POST /api/auth/logout`:
  * Reads current JWT, hashes it, and stores in Redis (`SET token:<hash> "BLACKLISTED" EX <remaining_ttl>`).

---

## 3. Strict Rules & Constraints
* Do not log plaintext passwords or raw tokens.
* Enforce unique constraint violations gracefully (HTTP 409 if email or username exists).

---

## 4. Done-When Command
```bash
./mvnw test -pl login-service,registration-service -Dtest=AuthAndRegistrationFlowTest
```
Test suite must pass verifying:
1. Registration creates user and auto-provisions PHP account.
2. Login with valid password returns JWT.
3. Logout writes token to Redis blacklist.
