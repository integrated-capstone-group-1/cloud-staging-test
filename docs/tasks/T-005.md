## 3. In-Scope Contract Slice
* Expose public port `:8080`.
* Implement route mapping:
  * `/api/auth/**` -> `http://login-service:8082` & `http://registration-service:8081` (Public)
  * `/api/v1/payments/**`, `/api/v1/cards/**` -> `http://transaction-service:8084` (Authenticated)
  * `/api/v1/accounts/**` -> `http://accounts-service:8083` (Authenticated)
  * `/api/v1/fx/**` -> `http://forex-service:8087` (Authenticated with JWT - Resolving B-08)
* **Block Internal Routes (B-08 Security Fix):**
  * Explicitly block `/api/accounts/credit`, `/api/accounts/debit`, and `/internal/**` from external caller access at the gateway with `403 Forbidden`.
* **Filter Chain:**
  1. Header Sanitization: Strip any incoming `X-Cust-Id` or `X-Cust-Role`.
  2. Rate Limiting: Redis token-bucket filter (15/s, burst 30/s per IP and User). Return `429 Too Many Requests` on flood.
  3. JWT Authentication: Verify signature and expiration.
  4. Token Blacklist Check: Query Redis key `token:<jwt_hash>`. If Redis is down during blacklist check, **fail closed with `401 Unauthorized`** (Resolving B-08).
  5. Decorate forwarded request with verified headers: `X-Cust-Id`.

## 4. Strict Rules & Constraints (Do Not Touch)
* Never allow unauthenticated calls to `/api/v1/fx/**`.
* Internal microservice ports (`:8081-8088`, `:1521`, `:5432`) must not be accessible directly from host.
