## 3. In-Scope Contract Slice
* Implement endpoints specified in [`docs/CONTRACTS.md`](file:///c:/Users/RBS83790/OneDrive%20-%20EastWest%20Banking%20Corporation/Documents/training/integrated-capstone/capstone-banking-system/docs/CONTRACTS.md):
  * `POST /api/v1/payments` (Exact match or funding-assisted shortfall).
  * `POST /api/v1/payments/{id}/cancel` (Customer cancel; CAS on `txn_status IN ('INITIATED', 'AUTHORIZED')`).
  * `POST /api/v1/admin/transfers/{id}/reverse` (Admin reversal).
* Implement CAS Claim (ADR-002):
  ```sql
  UPDATE transaction_master SET txn_status = 'PROCESSING', stage = 'SETTLING' 
  WHERE txn_id = ? AND txn_status = 'AUTHORIZED'
  ```
  If 0 rows updated, abort processing.
* Risk Action Handling (ADR-001):
  * Score $> 0.85 \implies$ set `txn_status` to `RESERVED`, stage `RISK_HELD`, place amount hold in CBS, and return `202 Accepted` or `422 DECLINED_HIGH_RISK`.
  * Risk timeout ($> 200\text{ms}$) $\implies$ set `txn_status` to `FAILED`, return `503 SECURITY_CHECK_UNAVAILABLE`.
* Delegate balance execution to `accounts-service` via `POST /internal/core/settlement` (with `capture_hold_id` if applicable).
