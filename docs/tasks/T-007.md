## 2. In-Scope Contract Slice
* Scheduled job runs `@Scheduled(cron = "0 0 * * * *")` fetching spot rates from `api.frankfurter.dev` for `EUR_PHP`, `USD_PHP`, `EUR_USD`, upserting into `fx_rate_cache` in PostgreSQL.
* `GET /api/v1/fx/quote?from=&to=&amount=`:
  1. Checks rate age: if `fetched_at` is older than 24 hours, return `422 FX_RATE_STALE`.
  2. Calculates spread: `spread_percentage = 1.50%`.
  3. Returns locked quote valid for 30 seconds (`expires_in_seconds = 30`).
  4. Stores quote temporarily in Redis or local cache for quote ID verification.

---

## 3. Strict Rules & Constraints
* Never call `api.frankfurter.dev` synchronously during a payment or quote request. Serve strictly from local `fx_rate_cache`.
* If external API fetch fails, keep last-known good rate and log a warning.
