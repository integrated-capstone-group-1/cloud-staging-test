# Task T-011: Admin Operations Portal & Customer 360 Dashboard

**Goal:** Implement the staff-facing Admin Web Portal in `frontend-web` using Spring Boot Thymeleaf, covering Customer 360 view, account freeze/unfreeze, held transaction reviews, and parameters editing.

**Requirement IDs:** BR-03, BR-09, BR-19, TR-A01, TR-P01, TR-P02, Additional Requirements #1, #6, #7

**Jira Mapping:** `DIG-17`, `DIG-50`, `DIG-51`, `DIG-52`, `DIG-54`

---

## 2. In-Scope Implementation Slice
* Hosted on port `:8090` with Spring Security enforcing `ROLE_ADMIN`.
* **Customer 360 View (`/admin/customers/{id}`):**
  * Displays customer legal KYC details.
  * Lists all active currency pockets and live balances.
  * Shows last 20 transactions across all accounts with status badges.
  * Shows Risk Engine screening history and flags.
* **Account Governance & Controls:**
  * **Admin Freeze / Unfreeze Button:** Invokes `POST /api/v1/admin/accounts/{id}/freeze` (sets `account_status = 'FROZEN'`, overriding customer lock).
* **Held Transactions Review Queue (`/admin/transfers/held`):**
  * Displays transactions flagged as `HELD_FOR_REVIEW` by the Risk Engine.
  * Admin buttons: **Approve (Release)** or **Reject**.
* **System Parameters Editor (`/admin/parameters`):**
  * Form allowing admins to view and edit transfer limits, AMLA thresholds, and FX spread percentages.

---

## 3. Strict Rules & Constraints
* Customer accounts must never be allowed access to `/admin/**` endpoints.
* Every admin action (freeze, parameter edit, release) must record `created_by` or audit logs.

---

## 4. Done-When Command
```bash
./mvnw test -pl frontend-web -Dtest=AdminPortalControllerTest
```
Test suite must pass verifying:
1. Non-admin users are blocked with 403 Forbidden.
2. Admin freeze successfully locks customer account.
3. Customer 360 aggregates customer, pocket balances, and transaction history.
