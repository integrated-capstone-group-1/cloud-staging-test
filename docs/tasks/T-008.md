## 3. In-Scope Contract Slice
* `GET /api/v1/cards`: Returns customer's virtual card with masked PAN (`4532-XXXX-XXXX-8821`), expiry, `card_status`, and `ecom_enabled`.
* `PUT /api/v1/cards/{id}/status`:
  * Updates `card_status` in `card_master` (`ACTIVE` <-> `FROZEN`).
* `PUT /api/v1/cards/{id}/ecom`:
  * Sets `ecom_enabled = 1` or `0`.
* In `PaymentOrchestrator`: If payment is flagged as e-commerce and `ecom_enabled == 0`, reject transaction (`HTTP 422 ECOM_TRANSACTIONS_DISABLED`).

## 4. Strict Rules & Constraints
* Full PAN must be tokenized, and CVV must never be persisted in the database (PCI-DSS compliance).
