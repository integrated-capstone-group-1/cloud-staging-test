## 2. In-Scope Contract Slice
* Expose internal endpoint: `POST /internal/risk/evaluate` as specified in [`docs/CONTRACTS.md`](file:///c:/Users/RBS83790/OneDrive%20-%20EastWest%20Banking%20Corporation/Documents/training/integrated-capstone/capstone-banking-system/docs/CONTRACTS.md#L240-L260).
* Compute weighted fraud score:
  $$S = \min\left(1.00, \; 0.35 \cdot V + 0.30 \cdot A + 0.20 \cdot D\right)$$
* Map score to action:
  * $S < 0.50 \implies \text{LOW} \implies \text{ALLOW}$
  * $0.50 \le S \le 0.85 \implies \text{MEDIUM} \implies \text{STEP\_UP\_OTP}$
  * $S > 0.85 \implies \text{HIGH} \implies \text{REJECT}$
* Returns response in $< 50\text{ms}$ typical execution time.

## 3. Strict Rules & Constraints
* **Pure Java:** Zero Python code.
* Stateless processing using fast in-memory or Redis sliding counters for velocity.
* Protect callers using Resilience4j `TimeLimiter` set to $200\text{ms}$.
