**Goal:** Set up the Flutter mobile application foundation with native KeyStore token storage, Dio API interceptors, auto-retry with backoff, and fail-fast client circuit breaker.

## 2. In-Scope Implementation Slice
* Initialize Flutter 3.x project with Material 3.
* Setup `flutter_secure_storage`:
  * Encrypted storage in Android KeyStore (`AES/GCM/NoPadding`) for JWT access token and refresh token.
* Setup `Dio` HTTP Client pointing to API Gateway (`http://10.0.2.2:8080` for Android emulator):
  * **Auth Interceptor:** Automatically injects `Authorization: Bearer <jwt>`.
  * **Idempotency Interceptor:** Generates and attaches `X-Idempotency-Key: <uuid>` on all POST/PUT mutation calls.
  * **Fail-Fast Circuit Breaker:** If 3 consecutive requests timeout (> 5s), trip state to `OPEN` and display `ServiceUnavailableScreen` with auto-retry countdown.

---

## 3. Strict Rules & Constraints
* Thin client only: Never compute balances, FX formulas, or business rules on the mobile device.
* Sensitive screens must block screenshots (`FLAG_SECURE`).
